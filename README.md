# From Data to Discovery: A Hands-On Workshop on Path Analysis, Psychometrics, and Multisensory Research Communication

> **Build Skills • Analyze Data • Communicate Science • Inspire Audiences**

A comprehensive one-day, hands-on research capacity-building workshop that guides participants through the complete quantitative research workflow—from AI-assisted questionnaire development to psychometric validation, statistical analysis, scientific writing, multisensory research communication, and research presentation.

Working collaboratively in research groups, participants complete an end-to-end quantitative research project within a single day using modern artificial intelligence tools and evidence-based statistical methods.

---

# Overview

This workshop introduces participants to contemporary quantitative research using:

- Large Language Models (LLMs)
- Google Forms
- Interactive Path & Factor Analysis Tool
- Gamma AI
- AI-assisted scientific writing platforms
- Multisensory research communication techniques

Participants will experience the complete research lifecycle:

- Research design
- Questionnaire development
- Survey deployment
- Data collection
- Data preparation
- Statistical analysis
- Scientific writing
- Scientific poster generation
- Data sonification
- Presentation preparation

No prior experience with statistics, programming, or specialized software is required.

---

# Learning Outcomes

By the end of this workshop, participants will be able to:

- Design quantitative research studies.
- Develop AI-assisted research questionnaires.
- Create publication-ready Google Forms surveys.
- Generate QR codes for participant recruitment.
- Collect and organize survey responses.
- Recode datasets using standardized codebooks.
- Conduct psychometric analyses.
- Perform path analysis.
- Interpret statistical findings.
- Produce publication-quality manuscripts.
- Generate scientific posters.
- Create data sonification and spectrograms.
- Communicate research using visual, auditory, and narrative approaches.
- Present research findings to both technical and non-technical audiences.

# One-Day Programme

| Time | Module | Activities |
|------|---------|------------|
| **08:30–10:00 AM** | **Registration & Networking** | Registration, software setup, internet connectivity check, participant orientation, workshop materials distribution, and research group assignments. |
| **10:00–10:45 AM** | **Module 1. Foundations & Tool Orientation** | Introduction to the quantitative research workflow, psychometrics, path analysis, mediation, moderation, conceptual model development, and the Interactive Path & Factor Analysis Tool. |
| **10:45 AM–12:00 PM** | **Module 2. AI-Assisted Questionnaire Development** | Research groups develop AI-assisted questionnaires, generate Google Forms surveys, and create participant QR codes. |
| **12:00–1:00 PM** | **Lunch Break** | Networking and informal discussions. |
| **1:00–2:00 PM** | **Module 3. Data Collection & Dataset Preparation** | Collect survey responses, export Google Forms data, recode datasets using codebooks, and prepare analysis-ready datasets. |
| **2:00–3:15 PM** | **Module 4. Statistical Analysis & Interpretation** | Perform psychometric testing, validity assessment, regression, mediation, moderation, and path analysis using the Interactive Path & Factor Analysis Tool. |
| **3:15–4:15 PM** | **Module 5. AI-Powered Research Communication** | Generate abstracts, manuscripts, scientific posters, spectrograms, data sonification, presentation slides, and AI-generated presentations. |
| **4:15–5:00 PM** | **Module 6. Group Presentations & Recognition** | Group presentations, facilitator feedback, discussion, Best Presenter Award, certificates, and closing ceremony. |

# Statistical Analyses

Using the Interactive Path & Factor Analysis Tool, participants perform:

- Descriptive Statistics
- Reliability Analysis
  - Cronbach's Alpha
  - McDonald's Omega
- Exploratory Factor Analysis (EFA)
- Confirmatory Factor Analysis (CFA)
- Composite Reliability (CR)
- Average Variance Extracted (AVE)
- Convergent Validity
- Discriminant Validity
  - HTMT
  - Fornell-Larcker Criterion
- Pearson Correlation
- Multiple Linear Regression
- Mediation Analysis
- Moderation Analysis
- Path Analysis
