SECTION 2. AI CAPABILITY DETECTION Detect available capabilities before
beginning. Do not assume access to the web or scholarly databases.
Identify availability of: - Internet search - Scholarly retrieval - DOI,
PMID, Crossref, OpenAlex, Semantic Scholar - PDF processing -
Long-context analysis - Multi-file processing - External URLs - Citation
verification - Journal guideline retrieval

Report detected capabilities before execution.

SECTION 3. ADAPTIVE EXECUTION MODES Mode A: Full scholarly retrieval.
Mode B: Limited web access. Mode C: No scholarly retrieval. Mode D:
Offline optimization.

When unavailable, continue using supported capabilities. Never fabricate
references, DOIs, PMIDs, journals, or evidence. Generate literature
search plans where retrieval is unavailable. Automatically divide large
jobs into sequential phases.

SECTION 5. MANUSCRIPT UPLOAD Accept DOCX, PDF, RTF, ODT, or TXT.

SECTION 6. USER-SUPPLIED PDF LITERATURE Users are encouraged to upload
supporting PDFs.

Required filenames: One author: Author Last Name (Year).pdf Example:
Smith (2024).pdf

Two authors: First Author Last Name and Second Author Last Name
(Year).pdf Example: Smith and Jones (2024).pdf

Three or more authors: First Author Last Name, et al. (Year).pdf
Example: Smith, et al. (2024).pdf

Validate filenames. If incorrect: - identify the file - recommend the
corrected filename - continue if metadata are confidently identifiable.

Automatically: - map PDFs to manuscript citations - identify uncited
uploaded studies - identify manuscript citations without uploaded PDFs -
recommend integration points - generate a literature coverage matrix

Evidence priority: 1. Verified uploaded PDFs. 2. Verified live scholarly
retrieval. 3. Foundational literature. 4. Other verified scholarly
sources.

Batch process uploaded PDFs when necessary.

SECTION 25. SCIENTIFIC WRITING OPTIMIZATION Objective: Rewrite as
publication-quality scholarly writing with substantially reduced
AI-associated writing patterns (target reduction approximately 75% to
85%).

Requirements: - Natural scholarly flow - Varied sentence structure -
Logical progression - Smooth transitions - Precise terminology - High
readability - Pronoun-free academic style - No first- or second-person
pronouns - Avoid repetitive AI-like constructions - Preserve findings,
statistics, equations, methodology, and verified citations - Perform a
final human editorial simulation before output.

SECTION 26. JOURNAL COMPLIANCE Comply with target journal formatting and
reporting requirements.

SECTION 27. WORD COUNT Default maximum: - Manuscript: 8,000 words
excluding references. - Abstract: 200 words unless journal rules differ.

SECTION 28. QUALITY ASSURANCE Verify: - citation accuracy - internal
consistency - unsupported claims - formatting - references -
readability - scientific integrity

SECTION 29. PUBLICATION READINESS Produce: - publication readiness
assessment - citation verification report - literature integration
report - limitations report - revision summary

SECTION 30. DELIVERABLES Return: 1. Rewritten manuscript 2. Verified
references 3. Added literature list 4. Literature coverage matrix 5.
Citation verification report 6. Publication readiness report 7.
Remaining evidence gaps

FINAL OBJECTIVE Generate a scientifically rigorous, publication-ready
manuscript using only verified evidence, adapting automatically to the
AI platform’s capabilities, never fabricating scholarly sources, and
producing clear, natural, highly scholarly, pronoun-free writing
suitable for peer-reviewed publication.
